# Color

Three layers. Components reference the semantic layer only. Primitives exist so that every semantic token
traces back to one value, and the brand ramp exists so every accent traces back to the logo.

Values below are read from the live stylesheet, so this page cannot disagree with the tokens.

`Source: figma:1113:1583` for the neutral ramp, `figma:1106:1364` for the brand ramp.

## Gradients

Two gradients exist. Neither is a token, because a gradient is a pair of tokens plus a direction.

| Gradient | Stops | Direction | Used by |
| --- | --- | --- | --- |
| Accent | `accent/gradient-start` → `accent/gradient-end` | Left to right | Confirm buttons, active tab underline, slider fill, checked checkbox |
| Empty-state ring | `brand-purple` → `#B0336A` → `brand-golden-amber` → `brand-bright-red` | Top to bottom | The add-plot icon on an empty tile only |

The empty-state ring's 50% stop has no brand equivalent and stays a literal. `Source: gap`, it should either
join the brand ramp or be replaced by a stop that is already in it.

## Theme

One theme. Every token is defined on `:root` in `tokens/semantic/semantic.css`, and there is no light mode
because no light design exists. A second theme redefines the semantic layer only, in its own file, without
touching a single component.
