# Typography

Three families, paired by role rather than used interchangeably. A component picks the family that matches
what the text is doing, not what looks right in isolation.

`Source: figma:1113:1583` for Inter and Lato, `figma:1019:10` for the mono column.

## Rules

- **Numbers that line up get `tabular-nums`.** Any column of digits, in a table or a readout.
- **Uppercase gets letter-spacing.** The readout label is the only uppercase style, at `0.04em`.
- **Weight carries emphasis, not size.** A selected option is the same size, at emphasis weight.
- **Mono means tabular, not code.** It marks a value a reader will compare against another value.

## Known gap

`Source: gap`. None of the three families is self-hosted. `tokens/primitives/typography.css` declares them
with system fallbacks but there is no `@font-face` and no CDN link, so the app currently renders in the
fallback stack. The decision between self-hosted `woff2` and a Google Fonts link is open. Until it is made,
every size above is correct and every rendered glyph is not.
