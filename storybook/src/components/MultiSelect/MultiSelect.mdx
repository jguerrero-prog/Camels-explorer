# MultiSelect

Several values from one field, each shown as a removable chip.

`Source: figma:1019:37`

## Anatomy

```
.multi-select
├── .multi-select__label
├── .multi-select__box        wrapping, padding 8, gap 6, surface/control
│   ├── .multi-select__chip[]   surface/chip, radius 6
│   │   ├── __chip-value
│   │   └── __chip-remove
│   ├── .multi-select__input    grows to fill the remaining row
│   └── .multi-select__chevron  only when `options` is supplied
├── .multi-select__menu       role="listbox", the unselected options
└── .multi-select__caption
```

Without `options` the control is type-only. With them, a chevron opens a menu of values not already added,
which is how realizations are picked from a known set.

## Tokens

| Token | Applies to |
| --- | --- |
| `--color-surface-control` | Box fill |
| `--color-surface-chip` | Chip fill |
| `--color-border-subtle` | Box border |
| `--color-surface-chrome` | Menu fill |
| `--color-surface-toggle-active` | Option hover |
| `--color-text-primary` | Chip values, options |
| `--color-text-muted` | Label, caption, remove affordance |

## Behaviour

- The box wraps. Adding chips makes it taller, never wider, so the sidebar column holds.
- Already-selected values are excluded from the menu rather than shown as disabled.
- The menu renders in a portal, like `SelectField`, so a scrollable ancestor cannot clip it.

## Accessibility

- The menu carries `role="listbox"` with `role="option"` children, and the trigger carries `aria-expanded`
  and `aria-haspopup`.
- `Source: gap`. Each chip's remove control has no accessible name, so a screen reader hears the value twice
  with no indication that the second is a remove button. Backspace does not remove the last chip.

## Content

Label plural, because the field holds several values: "Realizations to compare". The caption states how many
are available, not how many are chosen.

## Use it

- Several values of one field: realizations to compare, suites to compare.

## Don't use it

- For exactly one value. Use `SelectField`.
- For independent settings. Use several `Checkbox`es.
