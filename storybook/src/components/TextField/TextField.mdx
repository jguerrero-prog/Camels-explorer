# TextField

A plain editable field — the real "Realization" field from the Add Plot modal (Figma nodes `971:875` / `975:166`), a typed number rather than a fixed-list pick. Shares `SelectField`'s visual shell (same label/input/caption layout, same tokens) minus the chevron and menu, since this field has no option list at all.

## Token

- `--color-surface-control` / `--color-border-subtle` — input fill/border, same as `SelectField`
- `--color-accent-gradient-start` — focus ring color
- `--font-label` (Lato) — label and caption
- `--font-ui` (Inter) — the typed value

## Spec

- Label above (12px muted), input box (10px/12px padding, 8px radius), optional caption below (11px muted) — identical metrics to `SelectField`.
- `type="number"` for Realization; `type="text"` is the default for anything else that needs this same shell without a menu.

## Usecase

- Real, confirmed usage: the "Realization" field (0–999) in the Add Plot modal's Curated and Custom tabs — see `AddPlotModal.mdx`.
- Reach for this over `SelectField` when the field has no fixed option list to pick from; reach for `NumberStepper` instead if the real design shows increment/decrement buttons (it doesn't here — the real frame is a plain typed box).

## Code

```tsx
import { useState } from 'react';
import { TextField } from '@/components/TextField/TextField';

function RealizationField() {
  const [value, setValue] = useState('42');
  return (
    <TextField
      label="Realization"
      type="number"
      value={value}
      onChange={setValue}
      caption="0–999"
    />
  );
}
```
