# SimulationParametersSidebar

A configuration of the **Statistic sidebar** pattern, for Simulation parameters, a dataset rather than a summary statistic.

`Source: code`

This component owns no styles. It chooses which controls go inside `ParamsSidebar` and nothing else, so the
shell, its scroll behaviour, its fade and its pinned footer are all documented once in the pattern rather
than here.

**Read the pattern first:** Patterns / Statistic sidebar.

## Its configuration

This sidebar serves a dataset rather than one of the 19 summary statistics, so its controls are
not in the pattern page table. Open the story below to see them.
