# Button

The committed action in a context. Two variants that differ in emphasis and in size.

`Source: figma:1113:1591` (primary), `figma:1019:70` (secondary)

## Anatomy

```
button.button--primary
├── icon      optional, 18x18, decorative
└── label     Lato Bold 14
```

The icon sits before the label with an 8px gap. There is no trailing-icon arrangement.

## Variants and states

<Canvas of={ButtonStories.Primary} />

**Primary.** 40px tall, 16px horizontal padding, 12px radius, accent gradient, `0 8px 9px rgba(0,0,0,0.4)`
shadow, 14px label. One per context.

<Canvas of={ButtonStories.Secondary} />

**Secondary.** Auto height from 10px/14px padding, 8px radius, transparent fill, 1px `border/subtle`
outline, 13px label in `text/muted`.

<Canvas of={ButtonStories.NoIcon} />
<Canvas of={ButtonStories.LongContent} />

The two variants are different sizes, radii and text sizes because their source frames are. They are not one
shape in two colours, and unifying them would change both.

**Missing states.** `Source: gap`. There is no hover, active, focus or disabled treatment in either source
frame, and the component exposes no `disabled` prop. A disabled primary action currently has to be handled by
the caller, as the add-plot modal does by dropping the button's opacity to 0.5.

## Behaviour

- Renders `type="button"`, so it never submits a form by accident.
- Width hugs the label. It does not stretch to its container.
- The label does not truncate. A longer label makes a wider button.

## Accessibility

- Focus is the browser default outline. `Source: gap`, no focus ring is designed, and on a dark surface the
  default is weak. This is the highest-value accessibility fix available on this component.
- The icon is decorative and must be passed with an empty `alt`, so the label is the only accessible name.
- Primary label on gradient: white on `#7B2D8E` is 8.1:1, on `#E63946` is 3.9:1. The right-hand end of the
  gradient is below 4.5:1 for text under 18px. Keep labels short so they sit over the darker half.
- No `disabled` prop, so there is no `aria-disabled` state to convey.

## Content

Name the outcome, not the mechanism: "Add Plot", "Remove plot". Sentence case. No trailing punctuation.

## Use it

- **Primary** — the single committed action in a modal, a panel or the top nav.
- **Secondary** — a lower-emphasis action inside a panel, including destructive ones such as Remove plot.

## Don't use it

- For navigation. Use a link.
- For a toggle. Use `Checkbox` or `Radio`.
- For an icon with no label in a toolbar. Use `Toolbar`'s own tool button.
- Two primaries in one context. Demote one to secondary.
