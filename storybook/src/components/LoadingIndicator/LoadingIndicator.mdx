# LoadingIndicator

A 32px pill in the top nav while a fetch is in flight, with a way out.

`Source: code`

## Anatomy

```
.loading-indicator            32px, radius 9, surface/chrome, 1px border/subtle
├── .loading-indicator__icon  aria-hidden, bounces on a 0.9s loop
├── .loading-indicator__label Lato SemiBold 12, names what is loading
└── .loading-indicator__stop  20px button, Lato SemiBold 10
```

## Behaviour

- Sits in the top nav, matching the Add Plot button's 32px height so the bar never changes height.
- Stop discards whatever response is in flight and clears every tile's loading state. The request itself is
  not cancelled, which is invisible from the interface.
- The bounce respects `prefers-reduced-motion` and stops entirely when reduced motion is set.

## Accessibility

- The animated glyph is `aria-hidden`, so the label carries the meaning.
- `Source: gap`. The pill has no `role="status"` and no `aria-live`, so its appearance is silent to a screen
  reader. `Toast` already does this correctly and is the model to copy.

## Content

Name what is loading, not that something is: "Loading Power Spectrum…", not "Loading…". One trailing
ellipsis, no exclamation.

## Use it

- Any fetch long enough to notice, which in practice is every plot request.

## Don't use it

- Inside a tile. A tile shows its own loading state in place.
- For a failure. Use the component's inline error state.
