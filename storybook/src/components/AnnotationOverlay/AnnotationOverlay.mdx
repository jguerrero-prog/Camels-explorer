# AnnotationOverlay

Pins a comment to a point on a chart. Click the pin to open what it says.

`Source: code`

## Anatomy

```
.annotation-pin                  14px, accent gradient, z-index 5, positioned by percentage
└── .annotation-callout          240px, z-index 6, surface/content
    ├── __author-row            __dot (6px) + __time + __delete
    └── __text                  the comment

draft pin
└── .annotation-callout
    ├── __input                 textarea, placeholder "Add a note…", autofocused
    └── __actions               __cancel + __save
```

## Variants and states

<Canvas of={Stories.CalloutOpen} />

A pin has two lives. A **draft** pin is placed but not yet saved: its callout opens with an empty textarea,
Save stays disabled until the text is non-empty, and Cancel discards the pin. A **saved** pin shows its
text with a timestamp, and opens only when clicked.

## Tokens

| Token | Applies to |
| --- | --- |
| `--color-accent-gradient-start` → `--color-accent-gradient-end` | Pin fill, a 90° gradient |
| `--color-surface-content` | Callout fill |
| `--color-border` | Callout border |
| `--color-surface-control` | Textarea |
| `--color-text-muted` | Timestamp, and the author dot |
| `--font-label` | Author row |

The callout takes no drop shadow, so it reads as part of the page rather than floating above it.

## Behaviour

- Positions are fractional (`xFrac`, `yFrac`) and applied as percentages, so a pin stays on the same point
  when the tile resizes.
- One callout is open at a time: `activeId` is owned by the caller, and clicking the active pin closes it.
- Clicks are stopped at the pin and the callout, so opening a note does not also reach the chart underneath.
- Timestamps are relative and coarse: "just now", "5m ago", "3h ago", "2d ago".
- `hidden` on an annotation is honoured by the Hide popover's Annotations category, not by this component.

## Accessibility

- The delete control carries `aria-label` and `title`, and is revealed on `:focus-within` as well as hover,
  so it is reachable without a pointer once focus is inside the callout.
- `Source: gap`. The pin itself is a `div` with a click handler: not focusable, not a button, and not
  reachable by keyboard. The callout is not a dialog, takes no focus on open, and Escape does not close it.

## Content

The comment is the user's own words. The only text the interface supplies is the relative timestamp and the
placeholder, "Add a note…".

## Use it

- Marking a specific feature in the data for a colleague.

## Don't use it

- For a remark about the figure as a whole. Use `NoteOverlay`, which is not tied to a coordinate.
- For pointing without words. Use `ArrowOverlay`.
