A brief confirmation that an action completed, anchored above the canvas.

## Behaviour

- Positioning is the caller's decision. The component has no fixed placement; the app anchors it to the top
  centre of the canvas.
- Width hugs its content up to 380px, then the detail wraps on word boundaries.
- Dismissal is the caller's responsibility. The component does not time itself out.

## Accessibility

- Carries `role="status"`, so the title is announced without stealing focus. This is the correct pattern and
  the one `LoadingIndicator` should adopt.
- `Source: gap`. The check circle is decorative but not marked `aria-hidden`.
- The `ErrorState` story reuses the success green, which is wrong for a failure. Either give the component a
  tone prop or stop using it for errors.

## Content

Title states what happened in the past tense: "Copied provenance to clipboard". The detail echoes the exact
value so the reader can confirm it. No apologies, no exclamation marks.

## Use it

- Confirming a clipboard write or a completed background action.

## Don't use it

- For an error the user must act on. Put that inline, where the action is.
- For anything requiring a decision. A toast cannot be interacted with.
