# PlotTile

A populated panel: title, mode switch, the plot, its provenance, and optionally the rows behind it.

`Source: figma:1019:10`

## Anatomy

```
.plot-tile                  square corners, surface/content, padding 16/20, gap 12
├── .plot-tile__header
│   ├── title                 Inter Semi Bold 16
│   └── ChartModeDropdown     only when more than one mode is available
├── .plot-tile__body         min-height 340
│   ├── PlotChart | Plotly3DChart | Table
│   └── ParamsReadout         right when wide, underneath when narrow
├── UnderlyingHalos          optional
└── annotationOverlay        optional, absolutely positioned over the chart
.plot-tile--focused          1px border/selected ring
```

**Available modes are computed, not passed.** `static` appears only when the chart has an image, `table`
only when there are rows, `scatter3d` only with 3D data. With a single mode, `ChartModeDropdown` is not
rendered at all.

**The readout moves with width.** A full-width tile puts `ParamsReadout` in a 200px right-hand column. A
grid tile at 544px puts it underneath as a wrapping row. Layout follows the tile, not a prop.

## Behaviour

- Square corners, overriding `Tile`'s 12px. A populated panel sits on the page rather than floating above
  it. See Decision log, DR-004.
- The focused ring replaces the border rather than adding to it, so selection reads as colour, not weight.
- The tile scrolls internally rather than squeezing a chart below its minimum height.
- Clicking the chart reports fractional coordinates, which is how annotations, arrows and notes are placed.

## Accessibility

- `Source: gap`. The tile is a clickable `div` with no role, so focusing it by keyboard is impossible, and
  toolbar actions depend on focus. This is the most consequential accessibility gap in the app: a keyboard
  user cannot reach the tool targets at all.
- The focused ring is colour-only, with no non-colour indicator.
- Table mode is the accessible route to a chart's values.

## Content

Title is the statistic name exactly as the modal and the sidebar spell it.

## Use it

- One per plot on the canvas.

## Don't use it

- For an empty panel. Use `Tile`.
