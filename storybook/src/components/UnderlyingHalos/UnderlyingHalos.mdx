# Table (UnderlyingHalos)

The only data grid in the system. Shows the rows behind a plot, and is the accessible way to read a chart's
values.

`Source: figma:1019:133`

## Anatomy

```
.underlying-halos
├── __header            disclosure: chevron, label, count
└── __reveal
    ├── __controls          filter, finder picker, column menu, download
    ├── __table-container
    │   ├── __table-toolbar   appears on hover, in its own row above the table
    │   └── __table-wrap      max-height 420, scrolls both ways
    │       └── __table       JetBrains Mono 12, tabular-nums
    │           ├── th        sticky, Lato Regular 11, surface/control
    │           └── __th--pinned / __td--pinned   the frozen first column
    └── __footer            remaining count, fullscreen
```

The component is generic over its rows. `columns` defaults to the halo column set but any column definition
list works, which is why the same table serves the VIDE void catalog. `itemNoun` and `footerNoun` keep the
counts reading correctly for whatever the rows are.

## Behaviour

- Collapsed by default. The header states the row count so the reader knows whether expanding is worthwhile.
- The body scrolls to 420px rather than truncating, so the row count in the header matches what is reachable.
- Column headers are sticky. The first column is pinned horizontally and carries its own background, because
  a transparent pinned cell lets scrolled content show through it.
- The hover toolbar occupies its own row above the table at all times, so revealing it does not shift the
  table down.
- Numeric columns are right-aligned; the first column is left-aligned.
- Download exports the current rows as CSV, named by `csvFilename`.

## Accessibility

- Real `table`, `thead`, `th` and `td` elements, so row and column relationships are conveyed.
- The disclosure carries `aria-expanded`, and icon-only toolbar buttons carry `aria-label`.
- `Source: gap`. Sticky headers lack `scope="col"`, the sort controls are not announced as sort controls,
  and the hover-revealed toolbar is invisible to keyboard users until focused, which is the same problem in
  a different form.
- **This table is the accessibility fallback for charts.** Where a statistic has rows, the table mode is
  currently the only way to read its values without sight. That makes it worth more investment than its
  visual prominence suggests.

## Content

Column headers are the catalog's own field names with units in square brackets:
`Stellar Mass [Msun/h]`. Counts use thousands separators. The mass context note explains what a mass column
is relative to, in one sentence.

## Use it

- Under a plot, to expose the rows behind it.
- As the table mode of any tile whose data is rows.
- For any other row set, by passing `columns`.

## Don't use it

- For two or three values. Use `ParamsReadout`.
- For the full catalog. It renders what the tile already fetched, not billions of rows.
