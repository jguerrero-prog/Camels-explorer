# ParticleCloudChart

A 3D scatter of particle positions from one snapshot.

`Source: code`

## Anatomy

```
Plotly3DChart
└── scatter3d trace, mode markers
    marker size 1.5, colour #ffa53c, opacity 0.5
    pinEnabled false, so clicks never pin a mark
```

A configuration of `Plotly3DChart` with no styles of its own. It plots an `(N, 3)` array of positions in
Mpc/h. Marker size and opacity are what make a cloud of many points readable as structure rather than as a
solid block.

## Props

`positions` is the particle array. `rulerMode` hands clicks to distance measurement instead of selection.

## Tokens

None of its own. See `Plotly3DChart`.

## Behaviour

- Particle count is a sidebar setting, defaulting to 50,000. It is a render budget, not a physical quantity:
  the box holds far more particles than any browser should draw.
- Points are drawn unlit and uniform. Structure comes from density, not shading.

## Accessibility

Inherits `Plotly3DChart`, including its lack of a keyboard or screen-reader path.

## Content

Axis titles come from `Plotly3DChart`'s spatial defaults, in Mpc/h. A particle carries no scalar value, so
there is no colorbar and nothing to read out from a single point.


## Use it

- The 3D Particle Cloud statistic.

## Don't use it

- To count or measure. Use the catalog.
