# OptionSlider

A `Slider` over a list of values instead of a number range.

`Source: code`

## Anatomy

```
Slider    min 0, max options.length - 1, step 1
          the index is mapped back to the value on change
```

No styles and no markup of its own, so everything visual is documented on **Primitives / Slider**.

`formatValue` annotates a specific value where one is meaningful, for example marking `±0.5` as the
equilateral case.

## Props

Generated from `OptionSliderProps`. `options` is generic, so the value type is whatever the caller supplies.

## Tokens

None of its own. See **Primitives / Slider**.

## Behaviour

- The slider steps in whole indices, so every position is a valid option.
- Order is the array's order. Sort before passing if the list is not already meaningful in sequence.

## Accessibility

Inherits `Slider` entirely, including its gaps: the range input has no accessible name and the thumb has no
focus ring.

## Content

The label is the caller's. Values are shown by `formatValue`, so a list of grid sizes reads "128" rather
than an index. The reader never sees the index this component slides over.


## Use it

- A fixed, ordered list of values where adjacency is meaningful.

## Don't use it

- For an unordered list. Use `SelectField`.
- For a true continuum. Use `Slider` directly.

## Related
