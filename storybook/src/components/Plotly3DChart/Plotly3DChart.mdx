# Plotly3DChart

A rotatable 3D scene. The only chart with no server-rendered equivalent.

`Source: code`

## Anatomy

```
.plotly-3d-chart
├── (Plotly 3D canvas)
└── .plotly-3d-chart__clear-pin   appears once a point is pinned
```

## Behaviour

- Drag to orbit, scroll to zoom. Plotly owns the camera.
- `rulerMode` turns clicks into distance measurement between two points rather than selection.
- `pinEnabled` lets a reader pin a point so its values stay visible while the scene rotates. The clear
  control only appears once something is pinned.
- Axis labels default to the box coordinates in Mpc/h.

## Accessibility

- `Source: gap`. A WebGL canvas exposes nothing to assistive technology, and there is no keyboard path to
  orbit, zoom, pin or measure. There is no table fallback for 3D statistics, unlike 2D ones.
  This is the least accessible surface in the app and should be treated as a known limitation rather than an
  oversight.

## Content

Axis labels carry units: `x [Mpc/h]`. The pin readout shows coordinates at the same precision as the
readout column.

## Use it

- 3D Density Field and 3D Particle Cloud, the two statistics with volumetric data.

## Don't use it

- For 2D data rotated for effect.
- Where a reader needs the exact values. Offer the underlying catalog instead.
