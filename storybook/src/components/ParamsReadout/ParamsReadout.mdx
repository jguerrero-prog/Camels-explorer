# ParamsReadout

Read-only provenance on a plot tile: what produced this plot.

`Source: figma:1019:10`

## Anatomy

```
.params-readout
└── .params-readout__group[]
    ├── __label   Lato SemiBold 10, uppercase, letter-spacing 0.04em
    └── __value   JetBrains Mono 13
```

Two layouts, chosen by the tile's width rather than by a prop:

| Layout | When | Shape |
| --- | --- | --- |
| Right | The tile is full width, 1096px | 200px column, 1px left border, groups stacked |
| Bottom | The tile is a grid cell, 544px | Wrapping row, 1px top border, 24px gaps |

| `--font-mono` | Values |

## Behaviour

- Read-only. Nothing here is a control, and nothing is clickable.
- Values are monospace because a reader compares them between tiles.
- Labels are the only uppercase text in the interface, which is what marks this as metadata rather than
  content.

## Accessibility

- `Source: gap`. Label and value are adjacent paragraphs with no programmatic association, so a screen
  reader reads a run of unlabelled values. A description list would fix it.
- Uppercase is applied with `text-transform`, so the accessible name keeps its real casing. That is correct
  and worth preserving.

## Content

Labels are short and uppercase: `SUITE / SET`, `GRID / MAS`, `PARTICLE TYPE`. Values use the same formatting
as everywhere else: `IllustrisTNG · LH`, `512 · CIC`, joined by a middle dot.

## Use it

- On every populated plot tile, so a screenshot of a tile carries its own provenance.

## Don't use it

- For editable settings. Those belong in the sidebar.
- For a long list. Past about six groups the bottom layout wraps to three rows and stops being scannable.
