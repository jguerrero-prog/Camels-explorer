# FieldMapGroupControl

Chooses whether a 2D Field Map tile shows one map or a grid of consecutive realizations.

`Source: code`

## Anatomy

```
.field-map-group-control
├── __label     Lato Regular 12
├── __trigger   40px, radius 8, surface/control, aria-expanded
├── __menu      surface/popover
│   ├── GridSizePicker
│   ├── __divider
│   └── __reset   back to a single map
└── __caption   the realization range the current extent covers
```

## Behaviour

- The caption states the realization range the grid would cover, computed from the tile's current
  realization: choosing 4 by 4 from realization 42 reads "Realizations 42–57". The range is visible before
  committing, not after.
- Reset returns to a single map without closing and reopening the menu.

## Accessibility

- The trigger carries `aria-expanded` and `aria-haspopup`.
- `Source: gap`. The menu contains `GridSizePicker`, which is pointer-only, so this control inherits that
  limitation: a keyboard user can open the menu but cannot choose an extent.

## Content

The trigger reads the current state plainly: "Single map" or "4 × 4". The caption names the consequence, not
the setting.

## Use it

- On a 2D Field Map tile, to compare consecutive realizations side by side.

## Don't use it

- On any other statistic. Nothing else renders a mosaic.
