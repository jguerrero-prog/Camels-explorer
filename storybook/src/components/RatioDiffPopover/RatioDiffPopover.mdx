# RatioDiffPopover

Picks another tile to compare the focused tile against, as a ratio or a difference.

`Source: code`

## Anatomy

```
.ratio-diff-popover              role="dialog", aria-label="Compare against", 260px
├── __header > __eyebrow         "Compare against"
├── __row--new                   "New plot" / "Configure a fresh comparison target"
├── __divider
├── __candidates                 one __row per other tile: __checkbox + title + caption
│                                __row--disabled for an incomparable tile
│                                __empty when there are no other tiles
├── __divider
├── __mode-row                   Ratio · Difference, __mode-btn--active on the choice
└── __footer > __compare-btn     disabled until a target is selected
```

## Variants and states

<Canvas of={Stories.NoOtherTiles} />

Two states matter here, and both are about having nothing valid to compare against:

- **No other tiles** — the candidate list is replaced by "No other tiles yet", and the New plot row is the
  way forward.
- **An incomparable tile** — a tile showing a different statistic is still listed, but disabled, with its
  caption replaced by "Different statistic, axes aren't comparable". It is shown rather than filtered out so
  the user can see why it is not on offer.

Radius 12 and a single deep shadow, `0 12px 28px -6px rgba(0,0,0,0.45)`. `Source: gap`.

## Behaviour

- Only a tile showing the same statistic is offerable: two different statistics do not share an x-axis, so a
  ratio between them would not mean anything. Compatibility is decided by the caller.
- Selection is single, expressed as `selectedTileId`, even though the rows are checkboxes.
- Compare stays disabled until a target is selected, so the mode choice alone cannot be submitted.
- Escape closes it. `onClose` is optional in the type but the application always supplies it; a caller that
  omits it loses Escape.

## Accessibility

- `role="dialog"` with an `aria-label`, real checkbox inputs inside `label` elements, and Escape to dismiss.
- `Source: gap`. No `aria-modal`, no focus trap, no initial focus move, and no close button in the header,
  so Escape is the only way to dismiss it without choosing something.

## Content

- The eyebrow states the question: "Compare against".
- Modes are named for what they do: "Ratio", "Difference".
- A disabled row explains itself in its own caption rather than in a tooltip.

## Use it

- Showing how one feedback model departs from another.
- Comparing a variation against a fiducial run.

## Don't use it

- Across different statistics. The component already prevents this.
