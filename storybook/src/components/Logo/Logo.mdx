# Logo

The CAMELS mark, in two forms. Sized by height; width follows the artwork.

`Source: code`

## Anatomy

```
.logo    display block, width auto, height set by the height prop
```

Two assets, both raster:

| Variant | Asset |
| --- | --- |
| `icon` | `assets/camels-icon.png` |
| `wordmark` | `assets/camels-wordmark.png` |

Use the wordmark wherever the name should be read, and the icon only where the name is already established
or where there is no room for it. The icon is not a shortened wordmark; it does not say "CAMELS".

## Tokens

None. The mark is fixed artwork and is not recoloured by the theme.

## Behaviour

- `height` is the only size control. Width is `auto`, so the aspect ratio is always preserved and the mark
  cannot be stretched.
- The default height is set by the caller. There is no intrinsic default in the component.

## Accessibility

- `alt="CAMELS"` on both variants, so the mark is announced by name rather than by variant.

## Content

The mark is artwork and carries no editable text. Do not typeset "CAMELS" as a substitute for the wordmark.

## Use it

- In the top navigation, and anywhere the application identifies itself.

## Don't use it

- As a decorative element or a background.
- Recoloured, outlined, or on a ground that leaves it low-contrast.
- Scaled by width, which would require overriding the component's own rule.
