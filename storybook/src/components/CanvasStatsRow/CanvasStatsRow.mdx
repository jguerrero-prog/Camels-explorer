# CanvasStatsRow

A row of pill-shaped counters showing the size of the dataset behind an empty canvas.

`Source: figma:1113:1583`

## Anatomy

```
.canvas-stats-row           row, 12px gaps, full width
└── .canvas-stats-row__chip   flex 1, radius 999, surface/sunken, 1px border
    ├── __value              Lato Bold 12, text/primary
    └── __label              Lato Regular 12, text/muted
```

## Tokens

| Token | Applies to |
| --- | --- |
| `--color-surface-sunken` | Chip fill, the only use of pure black in the app |
| `--color-border` | Chip border |
| `--color-text-primary` | Value |
| `--color-text-muted` | Label |
| `--font-label` | Both |

## Behaviour

- Chips share the row width equally, so four chips each take a quarter regardless of content.
- Values come from the catalog, not from constants: 1,000 LH realizations, 4 suites, 19 statistics,
  5 halo finders.
- The row sits in the tile footer slot, under the empty state.

## Accessibility

- `Source: gap`. Value and label are separate spans with no association, so each chip reads as two
  fragments. Wrapping each chip's text in a single element would fix it.
- Contrast on `surface/sunken` is the highest in the app, since it is pure black.

## Content

Value first, then a lowercase label except where the term is a proper noun: `1,000 LH Realizations`,
`4 suites`, `19 Statistics`. Thousands separators always.

## Use it

- Under an empty canvas, to show the scale of what is available before anything is plotted.

## Don't use it

- For live filter counts. The Custom tab states those in a sentence, where the numbers are long.
- As navigation. Chips are not interactive.
