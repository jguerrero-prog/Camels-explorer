# GridSizePicker

Drag-free grid sizing: hover to preview an extent, click to choose it.

`Source: code`

## Anatomy

```
.grid-size-picker           column, centred, padding 10
├── .grid-size-picker__grid   132x132, 3px gaps
│   └── __cell[]              active cells fill with accent/gradient-end
└── .grid-size-picker__label  Lato Bold 12, reads back the hovered extent
```

Defaults to 6 by 6, the same extent as the table pickers in Google Docs and Word. Callers can reduce it;
field-map grouping has no use beyond about 6 by 6 in one tile.

## Tokens

| Token | Applies to |
| --- | --- |
| `--color-surface-control` | Inactive cells |
| `--color-border-subtle` | Cell borders |
| `--color-accent-gradient-end` | Active cells, fill and border |
| `--color-text-muted` | The extent label |

## Behaviour

- Hovering a cell highlights the rectangle from the top-left to it, and the label reads back that extent.
- Clicking commits. There is no drag and no confirm step.
- The grid is a fixed 132px square, so cell size falls out of the extent rather than the reverse.

## Accessibility

- Cells carry `aria-label` describing the extent they would select.
- `Source: gap`. The grid is pointer-only: there is no keyboard path to a cell, no roving tabindex and no
  arrow-key navigation. A keyboard user cannot set a grid size at all. Two number inputs would be a
  legitimate fallback.

## Content

The label reads `rows × cols` using a multiplication sign, not the letter x.

## Use it

- Choosing a small two-dimensional extent where seeing the shape beats typing two numbers.

## Don't use it

- For a one-dimensional count. Use `NumberStepper`.
- For extents beyond about 6 by 6.
