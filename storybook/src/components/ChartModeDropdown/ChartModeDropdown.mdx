# ChartModeDropdown

Switches how a tile draws its plot: a server image, an interactive render, 3D, or a table.

`Source: code`

## Anatomy

```
.chart-mode-dropdown
├── __trigger    28px pill, radius 7, surface/control, Lato SemiBold 12
│   └── __chevron  8x5
└── __menu       position fixed, role="listbox"
    └── __option[]  selected takes emphasis weight and an accent check
```

The option list is computed per tile, never fixed: `static` appears only when a server PNG exists for that
statistic, `table` only when the tile has halo rows, `scatter3d` only when it has 3D data. Options are never
shown disabled, because every listed option is selectable.

With only one available mode, `PlotTile` does not render this component at all.

## Behaviour

- The menu is `position: fixed`, so it escapes the tile's overflow and z-index context.
- Menu width is a `min-width` taken from the trigger, not a fixed width: "Interactive" is longer than
  "Static" and would otherwise be clipped by a pill sized to the current label.
- `white-space: nowrap` keeps a long option from wrapping into the checkmark.

## Accessibility

- The best-covered control in the system: `role="listbox"`, `role="option"`, `aria-selected`,
  `aria-expanded` and `aria-haspopup` are all present.
- `Source: gap`. Arrow-key navigation between options is still missing.

## Content

Mode names are single words where possible: Static, Interactive, Table, 3D. They name the output, not the
technology.

## Use it

- In a plot tile header, when a tile can render its data more than one way.

## Don't use it

- For choosing data. That is a field, in the sidebar.
- When only one mode is available. Render nothing.
