# PlotChart

The plot surface. Renders either a server-made image or an interactive Plotly chart, on the same white card.

`Source: figma:1019:10`

## Anatomy

```
.plot-chart              surface/chart, 8px padding
├── .plot-chart__image   the server PNG, when displayMode is static
└── (Plotly canvas)      when displayMode is interactive
.plot-chart__error       replaces either when the fetch failed
```

The card is white on purpose. Every other surface in the app is dark; a scientific line or log plot needs
axes and data to read against white. See Foundations / Color.

**Static.** `imageUrl` points at a `plot.png` endpoint and the browser shows the finished image. This is the
default for the 17 statistics that have a server renderer.

**Interactive.** The same numbers redrawn by Plotly, so the reader can zoom and hover. Available whenever
the chart is not image-only.

**Error.** When the image or the data fails, the card shows an inline message naming the likely cause,
which is usually that the backend is not running.

## Tokens

| Token | Applies to |
| --- | --- |
| `--color-surface-chart` | The card, deliberately white |
| `--font-ui` | The inline error message |

Plotly draws its own axes and gridlines and does not read these tokens.

## Behaviour

- `logX` and `logY` set axis scaling, not formatting. Most CAMELS quantities span several decades.
- `mode` chooses lines or markers. Lines for a spectrum, markers for a scatter.
- `markerColor` adds a third dimension with a colour bar and a title.
- `onForceInteractive` lets a caller switch away from the static image, which is how a failed PNG falls back.

## Accessibility

- `Source: gap`. This is the weakest area in the system. The static image has no meaningful `alt`, so the
  plot is invisible to a screen reader. The interactive canvas exposes no data at all.
- The table mode reached through `ChartModeDropdown` is the accessible equivalent, and is currently the only
  way to read a plot's values non-visually. Offering it wherever rows exist matters more here than anywhere
  else.
- Colour alone distinguishes compared series.

## Content

Axis labels carry units in square brackets exactly as the backend returns them: `k [h/Mpc]`,
`P(k) [(Mpc/h)³]`. Do not reformat them in the client.

## Use it

- Any statistic with a numeric series or a server-rendered image.

## Don't use it

- For 3D data. Use `Plotly3DChart`.
- For a grid of images. Use `FieldMapMosaic`.
- For rows of numbers. Use the table.

## Related

- `StaticImageChart` — image-only, no interactive path
