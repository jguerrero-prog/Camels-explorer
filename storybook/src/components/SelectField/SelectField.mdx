# SelectField

Picks exactly one value from a fixed list. The workhorse field of the params sidebar and the add-plot modal.

`Source: figma:1055:28` for the closed field, `code` for the open menu

## Anatomy

```
.select-field
├── label            Lato Regular 12, text/muted
├── .select-field__input          the trigger
│   ├── value        Inter Regular 14, centred, truncates with an ellipsis
│   └── chevron      10x6 triangle, points down when closed
├── caption          optional, Lato Regular 11, text/muted
└── .select-field__menu           portalled to document.body when open
    ├── search       optional, only when `searchable`
    ├── option[]     33px rows; selected row is emphasis weight with a check
    └── fade         only while the list is scrolled short of its end
```

## Behaviour

- Opens on trigger click. Closes on selecting an option, clicking outside, pressing Escape, or scrolling the page.
- The menu renders in a `document.body` portal at `position: fixed`, positioned from the trigger's bounding
  rect, so a scrollable ancestor cannot clip it. See Decision log, DR-005.
- Scroll events originating inside the menu's own list do not close it.
- A long value truncates with an ellipsis rather than overlapping the chevron.
- `searchable` filters on a case-insensitive substring and resets the query each time the menu opens.
- A disabled option is rendered and announced but never fires `onChange`.
- The menu's scrollbar is always visible rather than an overlay. See Decision log, DR-006.

## Accessibility

- The trigger is a `button`. The menu is a `ul` of `button` rows.
- `Source: gap`. Three things are missing and are worth fixing together: arrow-key navigation between
  options, `role="listbox"` with `aria-expanded` and `aria-activedescendant` on the trigger, and a visible
  focus ring. Today the menu is mouse-and-Escape only.
- Disabled options need `aria-disabled`, not just reduced opacity.
- Label and value are both above 4.5:1 on their own surfaces.

## Content

- Label in sentence case, units in square brackets: `Min stellar mass [Msun/h]`.
- Expand an acronym once in the option itself: `LH · Latin Hypercube`, joined by a middle dot.
- Captions state a count or a constraint, not an apology: `1,000 realizations`.

## Use it

- Exactly one value from a fixed list: suite, set, statistic, field, chart type.
- With `searchable` once the list passes roughly twenty options.

## Don't use it

- For several values at once. Use `MultiSelect`.
- For a continuous number. Use `Slider`, or `NumberStepper` when the value is typed.
- For two mutually exclusive options that both fit on screen. Use `Radio`.
- For a chart-level mode switch on a tile header. Use `ChartModeDropdown`.

## Related

- `Radio` — two or three options, no menu
