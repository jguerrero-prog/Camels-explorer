# Checkbox

An independent on/off setting. One per line, label to the right of the box.

## Behaviour

- Renders a `button`, not an `input`, so the whole row including the label is one hit target.
- Clicking anywhere on the control toggles it. There is no separate label-click behaviour to get wrong.
- The box never changes size between states, so a column of checkboxes does not shift when one is ticked.

## Accessibility

- `Source: gap`. It is a `button` with no `role="checkbox"` and no `aria-checked`, so a screen reader
  announces it as a plain button and never reports its state. Adding both attributes is a two-line fix and is
  the highest-value change on this component.
- Keyboard activation works, because it is a real button.
- Disabled is visual only. It needs `aria-disabled` alongside the opacity change.
- Label contrast is `text/primary` on `surface/chrome`, comfortably above 4.5:1.

## Content

Sentence case, stating what being on means: "Compare mode", "Log scale (X)", "Overlay VIDE void catalog".
Never phrase it as a question, and never negate it: "Hide legend" rather than "Don't show legend".

## Use it

- An independent setting that does not exclude any other setting.
- Turning an overlay or a mode on and off inside a params sidebar.

## Don't use it

- For one of several mutually exclusive options. Use `Radio`.
- For a single value from a longer list. Use `SelectField`.
- As a list-row selector. This component has no indeterminate state.
