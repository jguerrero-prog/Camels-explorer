# CustomAggregateChart

Renders a precomputed aggregate from the catalog: a histogram, a heatmap or a box plot.

`Source: code`

## Anatomy

```
Plotly trace, chosen by the aggregate kind
├── histogram   bar trace over precomputed bin edges and counts
├── heatmap     2D bins, one z value per cell
└── box plot    one box per bin of the grouping field
```

No styles of its own. The server computes the bins; this draws them. The Custom tab never plots raw rows
for an aggregate, because the catalog holds billions of them.

The chart kind follows the shape of `data`, not a separate prop: `CustomHistogramData`, `CustomHeatmapData`
and `CustomBoxplotData` are distinguished by their fields.

## Tokens

None of its own. It renders onto `PlotChart`'s card.

## Behaviour

- Bins come from `GET /api/custom/histogram`. This component performs no binning.
- Axis labels are the catalog field names, underscores included, because that is what the reader chose in
  the picker.

## Accessibility

- `Source: gap`. Same as every Plotly surface: the canvas exposes no values. A heatmap additionally carries
  meaning in colour alone.

## Content

Axis titles are the catalog's own field names and units, so a chart can be matched against a query. The
aggregate kind is named the way the sidebar names it: histogram, heatmap, box plot.


## Use it

- A Custom tab plot whose chart type is an aggregate rather than a scatter.

## Don't use it

- For a curated statistic. Those have their own endpoints and server renderers.
- For raw rows. Use the scatter path.
