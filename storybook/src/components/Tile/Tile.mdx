# Tile

An empty panel inviting the first plot. The rounded, shadowed card that `PlotTile` replaces once filled.

`Source: figma:1113:1583`

## Anatomy

```
.tile                    radius 12, surface/content, 1px border, padding 16/20, gap 12
├── .tile__title           Inter Semi Bold 16
├── .tile__empty-state     centred, gap 12, fills the remaining height
│   ├── .tile__empty-icon    56px, radius 16, four-stop gradient ring
│   └── .tile__empty-caption Lato Regular 14
└── footer                 optional slot, usually CanvasStatsRow
```

## Tokens

| Token | Applies to |
| --- | --- |
| `--color-surface-content` | Card fill |
| `--color-border` | Card border, and the icon's inner fill |
| `--color-text-primary` | Title |
| `--color-text-muted` | Caption, plus icon |
| `--color-empty-icon-gradient-1..4` | The icon's ring, top to bottom |

The ring is a four-stop gradient, richer than the two-stop accent used everywhere else, and it is the only
place those four tokens appear. Its 50% stop is a literal with no brand equivalent. See Foundations / Color.

## Behaviour

- The whole empty state is one button, so the target is the area rather than the 56px icon.
- Hover scales the icon to 1.04 and adds a faint warm glow.
- The card keeps 12px radius and a shadow. `PlotTile` deliberately drops both. See Decision log, DR-004.

## Accessibility

- `Source: gap`. The empty state is a `button` with no accessible name beyond its caption text, and the
  icon is not marked decorative. The hover scale has no `prefers-reduced-motion` guard.

## Content

Title names the panel: "Panel 1". Caption names the action: "Add a plot or simulation".

## Use it

- For an empty panel, as the canvas starter.

## Don't use it

- Once a plot exists. Use `PlotTile`.
- As a generic card. The empty state is not optional.
