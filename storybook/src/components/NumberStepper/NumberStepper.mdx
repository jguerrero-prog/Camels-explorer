# NumberStepper

A typed number with increment and decrement buttons. Use when the exact value matters.

`Source: figma:1019:37`

## Behaviour

- The value is typeable, so a user going to realization 847 types it rather than clicking 847 times.
- `step` defaults to 1. `formatValue` controls display only: pass `(v) => v.toFixed(1)` for `10.0`.
- The buttons are 14px, deliberately small, because typing is the primary path.

## Accessibility

- The stepper buttons carry `aria-label`, so increment and decrement are distinguishable.
- `Source: gap`. The value input has no associated `label` element and no `aria-label`, so the field name is
  not announced. It also lacks `role="spinbutton"` with `aria-valuenow`, `aria-valuemin` and `aria-valuemax`,
  which is what would make the caption's range available to a screen reader.
- Arrow-key stepping inside the input is not implemented.

## Content

Label in sentence case with units in square brackets. The caption states the range as `0–999` with an en
dash, or a constraint such as "Integers only".

## Use it

- A precise value the user is likely to know: Realization, z min, z max, a mass bound.
- Anywhere the valid range needs stating alongside the control.

## Don't use it

- For an approximate position on a range. Use `Slider`.
- For two bounds. Use `RangeFilterControl`.
- For a value from a fixed list. Use `SelectField` or `OptionSlider`.
