# HidePopover

Hides annotation layers so a plot can be read, or screenshotted, without them. Four categories, two scopes.

`Source: code`

## Anatomy

```
.hide-popover                role="dialog", aria-label="Hide", 260px
├── __pointer                the triangle aimed at the toolbar button
├── __header                 __title "Hide" + __close-btn
├── Radio "Apply to"         This panel · All panels
├── __caption                shown only when "This panel" has no focused tile
└── __checkboxes             Annotations · Arrows · Notes · Param readouts
```

The last story is the one to understand. "This panel" needs a focused tile to act on. With none, the
checkboxes are disabled and a caption says to click a tile first, rather than offering controls that would
silently do nothing.

## Tokens

| Token | Applies to |
| --- | --- |
| `--color-surface-popover` | Popover fill |
| `--color-surface-content` | Pointer fill |
| `--color-border-subtle` | Border, and the pointer's two visible edges |
| `--color-text-primary` / `--color-text-muted` | Title, caption |
| `--font-label` | Title |

Radius 12, and a two-layer shadow: `0 6px 8px rgba(0,0,0,0.2)` with `0 18px 20px rgba(0,0,0,0.4)`.
The popover family shares this treatment. `Source: gap` for both the shadow and the radius.

## Behaviour

- Hiding is non-destructive. Annotations, arrows, notes and readouts stay in the tile's state and reappear
  when unhidden.
- Scope and values are owned by the caller, so what this popover shows is whatever the application has
  applied. Closing it does not reset anything.
- `panelDisabled` disables the categories rather than the scope control, so the reason for the state stays
  visible.
- Escape closes it, via a document key listener removed on unmount.

## Accessibility

- `role="dialog"` with an `aria-label`, a labelled close button, and Escape to dismiss.
- Composed from real `Radio` and `Checkbox` controls, so the whole body is keyboard operable.
- `Source: gap`. No `aria-modal`, no focus trap, focus is not moved in on open or restored on close, and the
  disabled-state caption is not tied to the controls it explains.

## Content

Category names match what the tools are called elsewhere: Annotations, Arrows, Notes, Param readouts. The
scope reads "This panel" and "All panels", matching the word the toolbar uses for a tile.

## Use it

- Reading a dense plot without annotation clutter.
- Clearing the view before a screenshot.

## Don't use it

- To delete annotations. There is no bulk delete, deliberately.
- To hide plotted data. Hiding applies to annotation layers, not to curves.
