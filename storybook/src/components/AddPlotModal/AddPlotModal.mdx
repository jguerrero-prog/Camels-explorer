# AddPlotModal

The dialog shell for adding a plot. Two tabs: a ready-made statistic, or one built from the catalog.

`Source: figma:1113:1583`

## Anatomy

```
.add-plot-modal-backdrop     black at 60%
└── .add-plot-modal          440px, radius 16, surface/content
    ├── __header             padding 20/20/16/24: title + 28px close
    ├── __divider
    ├── __tab-row            gap 24; the active tab takes a 2px accent underline
    ├── __fields             fixed 260px of content height, scrolls
    │   └── __fields-fade    48px, only while scrolled short of the end
    ├── __footer-divider
    └── __footer             hint left, Cancel and Add Plot right
```

**The field area height is fixed at 260px.** Curated needs three dropdowns; Custom needs ten fields and a
filter tree. Without a fixed height the dialog resized when switching tabs, moving the tab row and footer
under the cursor. Custom scrolls inside it. See Decision log, DR-009.

**The confirm button states why it is disabled.** The footer hint sits at the leading edge and names the
missing input rather than leaving a dead button.

## Behaviour

- Opens from the single Add Plot button in `TopNav`.
- The fade renders only when the field area is actually scrollable, so Curated never shows one.
- The field area has 56px of bottom padding, taller than the 48px fade, so the last control clears the
  gradient entirely.
- Confirm stays disabled until the chosen tab's required fields are set.

## Accessibility

- Carries `role="dialog"` with `aria-modal` and an `aria-label`, which is the best dialog implementation in
  the app.
- `Source: gap`. Focus is not trapped and not moved into the dialog on open, and is not restored to the Add
  Plot button on close. The tabs are buttons without `role="tab"` or `aria-selected`.

## Content

Title: "Add a plot or simulation". Tabs: "Curated", "Custom". The hint names what is missing: "Pick a Type
and the required fields for this chart type to continue."

## Use it

- Once, as the only route to adding a plot.

## Don't use it

- For settings on an existing plot. Those are in the sidebar.
