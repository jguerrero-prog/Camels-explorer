# ArrowOverlay

An arrow drawn on a chart from two clicks. One SVG layer holds every arrow on a tile.

`Source: code`

## Anatomy

```
svg.arrow-overlay                   fills the tile, z-index 4
├── defs > marker#arrow-overlay-head    8×8 filled triangle, orient auto
├── line.arrow-overlay__line            2.5px stroke, markerEnd = the head
└── circle.arrow-overlay__draft-point   r=4, the first click while awaiting the second
```

## Variants and states

<Canvas of={Stories.AwaitingSecondClick} />

There are only two states: arrows, and arrows plus a draft point. The draft point is what tells the user
the first click registered, since nothing else on screen changes until the second.

## Tokens

| Token | Applies to |
| --- | --- |
| `--color-accent-gradient-end` | Line stroke, arrowhead fill, draft point |

A single flat colour rather than the accent gradient: a 2.5px stroke and an 8px arrowhead cannot carry one.

## Behaviour

- Endpoints are fractional (`xFracA`/`yFracA` to `xFracB`/`yFracB`) and set as percentages, so an arrow
  keeps its meaning when the tile resizes.
- Clicking a line deletes that arrow, and the click is stopped so it does not also reach the chart.
- The arrowhead is a shared `marker` definition, so every arrow points the same way at any angle.
- `hidden` on an arrow is honoured by the Hide popover's Arrows category, not here.

## Accessibility

- `Source: gap`. The least accessible overlay in the application: the SVG and its shapes carry no role,
  label or title; there is no keyboard path to draw an arrow or delete one; and click-to-delete happens
  immediately, with no confirmation and no undo.

## Content

None. The arrow carries no text, which is the reason to pair it with an annotation or a note.

## Use it

- Pointing at a feature where a pin would sit on top of the data.
- Connecting a note to the thing it refers to.

## Don't use it

- To carry words. Use `AnnotationOverlay` or `NoteOverlay`.
- As a measurement. The arrow records no length or value.
