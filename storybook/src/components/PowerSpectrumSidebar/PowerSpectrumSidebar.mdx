# PowerSpectrumSidebar

A configuration of the **Statistic sidebar** pattern, for Power Spectrum.

`Source: code`

This component owns no styles. It chooses which controls go inside `ParamsSidebar` and nothing else, so the
shell, its scroll behaviour, its fade and its pinned footer are all documented once in the pattern rather
than here.

**Read the pattern first:** Patterns / Statistic sidebar.

## Its configuration

After Suite, Set and Realization it adds:

> Compare mode, Snapshot, Grid size, Mass Assignment Scheme, Threads, Particle type, k range, Overlay linear-theory Pk (z=0, from ICs)
