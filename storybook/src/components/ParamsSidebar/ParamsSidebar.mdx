# ParamsSidebar

The 280px panel that holds a statistic's controls. It owns the shell only; the caller supplies the fields.

`Source: figma:1113:1583`

## Anatomy

```
.params-sidebar                280px, surface/chrome, 1px right border, padding 24 0
├── __header       padding 0 20, gap 18
│   ├── __title    Inter Semi Bold 18
│   └── __divider  1px border/default
├── __scroll-wrap  flex 1, min-height 0
│   ├── __scroll   gap 18, padding 0 8 0 20, overflow-y auto
│   └── __fade     48px gradient, only while scrolled short of the end
└── __footer       padding 0 20, pinned, never scrolls
```

The asymmetric scroll padding is deliberate: 20px on the left to line up with the title, 8px on the right so
the scrollbar sits in its own gutter instead of against the controls.

## Behaviour

- Fixed 280px wide. The panel does not resize with its content.
- Only `__scroll` scrolls. The title and the footer stay put.
- The fade renders only when there is more content below, and hides at the end of the list.
- Overflow detection uses a `MutationObserver` and a `ResizeObserver`, not just scroll events: this wrapper is
  sized by flexbox, so its own box does not change when content grows. Only `scrollHeight` does.
- The scrollbar is always visible rather than an overlay. See Decision log, DR-006.

## Accessibility

- The panel is a plain container, so screen-reader order is the control order. Compose fields in the order a
  reader should meet them.
- `Source: gap`. The panel has no landmark role and no accessible name, so it is not reachable as a region.
  Adding `role="region"` with `aria-label={title}` would fix it in one line.
- The scroll region is keyboard-scrollable because it is focusable content, but it carries no
  `tabindex`, so an empty panel cannot be scrolled by keyboard alone.

## Content

The title is the statistic's name exactly as it appears in the Add Plot modal, so the two agree. Field
labels follow Content and units.

## Use it

- One per focused plot tile, showing that statistic's controls.
- Always pass a footer with Remove plot, so it stays reachable when the controls overflow.

## Don't use it

- For the Custom tab's field pickers. Use the Custom plot pattern.
- For a panel on the right. This is a left-hand chrome element, with a right border to prove it.
- As a generic scroll container. It carries a title, a divider and a pinned footer.
