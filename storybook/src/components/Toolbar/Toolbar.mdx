# Toolbar

The tool row that sits in the header between the folder/project name and "Add Plot" — real across all three frames it appears in (Figma nodes `1078:30`, `1068:48`, `1046:40`), identical every time, so this is a stable, confirmed component, not a one-off mock.

## Token

- `--color-border-subtle` — the active-tool background tint
- `--color-surface-toggle` / `--color-surface-toggle-active` — the grid/stacked view-mode toggle's own background and its selected option

## Spec

Left to right: **Annotate → Arrow → Note → Hide → Ratio/diff → Ruler → Linked brushing → Copy provenance → Copy as code** (nine 36×36 tools, 18×18 icons, 8px radius) → an 8px spacer → a grid/stacked **view-mode toggle** (32×32 options inside a padded, rounded container).

**Real addition (2026-08-06, direct user feedback): Hide.** Opens a popover (`HidePopover.mdx`) with 4 checkboxes - Annotations, Arrows, Notes, Param readouts - plus a This-panel/All-panels scope switch. Same `toolbar__tool-wrap`/`toolbar__popover-anchor` pattern as Ratio/diff and Copy as code (a real popover tool, not a toggle-mode one - no `hideActive` prop, the button's own look never changes).

**Real fix (2026-08-06, direct user feedback): the AI agent icon was removed.** It was a named-but-unwired skeleton slot from the very first pass of this component and never gained real behavior - rather than continue carrying a permanently-inert button (and the divider that only existed to separate it from the real tools), both were deleted outright. Every remaining tool listed above is fully wired to real behavior in `App.tsx` - this is no longer a skeleton-level component.

- The real `tool-ratio-diff` icon in Figma had small chevron overlays baked into its own SVG - simplified to the same plain icon-button treatment as its siblings (a deliberate choice, not a missed detail), then further reworked 2026-08-06 (removed the chevron, adjusted the glyph's own scale) after direct feedback that it read visibly smaller than the rest of the row.

## Usecase

- **Resolved 2026-08-05:** lives inside `TopNav`'s header row via its real `toolbar` prop (see `TopNav.mdx`) — `App.tsx` originally rendered this as a second row beneath `TopNav`, a real layout bug fixed once the real merged-header frame (Figma node `1012:1124`) confirmed it belongs in the same row.
- `viewMode` should be lifted to whatever owns `Viewer` (see `Viewer.mdx`) — this component doesn't own view-mode state itself, it just displays/toggles it.

## Code

```tsx
import { useState } from 'react';
import { Toolbar } from '@/components/Toolbar/Toolbar';
import type { ViewMode } from '@/components/Toolbar/Toolbar';

function Header() {
  const [viewMode, setViewMode] = useState<ViewMode>('grid');
  return <Toolbar viewMode={viewMode} onViewModeChange={setViewMode} />;
}
```
