# Toolbar

Nine tools that act on the focused tile, plus the grid and stacked view switch.

`Source: figma:1078:30`

## Anatomy

```
.toolbar                     row, 4px gaps
├── .toolbar__tool[]           36px, radius 8, 18px icon; active takes border/subtle
│   └── .toolbar__popover-anchor  centred 12px below, for tools that open one
├── .toolbar__spacer           8px
└── .toolbar__viewmode         padding 2, radius 8, surface/toggle
    └── __viewmode-option[]    32px, radius 6; active takes surface/toggle-active
```

Tools in order: annotate, arrow, note, hide, ratio/diff, ruler, linked brushing, copy provenance, copy as
code.

## Variants and states

<Canvas of={Stories.StackedActive} />

Tools are either momentary actions or sticky modes. A sticky tool stays filled while active, which is what
`annotateActive`, `arrowActive` and `noteActive` drive.

## Tokens

| Token | Applies to |
| --- | --- |
| `--color-border-subtle` | Active tool fill, divider |
| `--color-surface-toggle` | Viewmode container |
| `--color-surface-toggle-active` | Selected viewmode |

## Behaviour

- Tools operate on the focused tile, so the focused ring is a prerequisite, not decoration.
- A tool that opens a popover anchors it centred 12px below itself.
- The viewmode switch changes the canvas layout: grid puts two tiles per row, stacked gives each full width.

## Accessibility

- Tools carry `aria-label` and `aria-pressed`, so icon-only buttons announce purpose and mode state.
- `Source: gap`. No `role="toolbar"` and no arrow-key navigation between tools, so a keyboard user tabs
  through all eleven controls. No visible focus ring.

## Content

Labels are verbs: "Annotate", "Add note", "Hide series", "Copy as code".

## Use it

- Once, inside `TopNav`.

## Don't use it

- For actions that do not need a focused tile.
