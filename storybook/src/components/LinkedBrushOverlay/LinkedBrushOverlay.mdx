# LinkedBrushOverlay

Drag an x-range on one tile; every other tile shows the same range.

`Source: code`

## Anatomy

```
.linked-brush-overlay                fills the tile, z-index 3
├── --capturing                      the brushing mode is active
├── __band                           accent at 18%, 1.5px accent edges left and right
└── __badge                          __badge-dot + label + __clear
```

The **source** tile is the one the drag happened on and shows its own label in the badge. A **mirrored**
tile shows the same band with the badge reading `LINKED`, so it is always clear which tile owns the
selection and which are following it. With no selection the overlay renders nothing at all.

During a drag the band follows the pointer but the badge is suppressed, so a label does not chase the
cursor across the plot.

## Tokens

| Token | Applies to |
| --- | --- |
| `--color-accent-gradient-end` | Band edges, badge dot |
| `--color-surface-content` | Badge fill |
| `--color-border-subtle` | Badge border |
| `--color-text-primary` / `--color-text-muted` | Badge label, clear control |

The band fill is a literal `rgba(230, 57, 70, 0.18)`, the accent at an opacity no token expresses.
`Source: gap`.

## Behaviour

- The band is x-only. There is no y or rectangular selection.
- Bounds are fractional and applied as percentages, so a band mirrors correctly onto tiles of any width.
- A drag under 1% of the width is discarded, so a stray click does not create an unusably narrow selection.
- Bounds are normalised, so dragging right-to-left works.
- Pointer handling only engages when `captureActive` is set; otherwise the layer is inert and the chart
  underneath behaves normally.

## Accessibility

- The clear control carries `aria-label` and `title`.
- `Source: gap`. Brushing is drag-only with no keyboard equivalent, and a change of selection is not
  announced.

## Content

The badge names the source tile, or reads `LINKED` on a tile that is following one. It does not report a
count of selected points.

## Use it

- Comparing the same x-range across several statistics at once.

## Don't use it

- For zooming. In interactive mode Plotly owns zoom.
- For selecting rows. Use the table view.
