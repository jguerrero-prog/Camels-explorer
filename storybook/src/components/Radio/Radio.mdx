# Radio

A segmented control for two or three mutually exclusive options, all visible at once.

`Source: figma:1019:37`

## Anatomy

```
.radio
├── .radio__label      Lato Regular 12, text/muted
├── .radio__group      role="radiogroup", 2px padding, radius 8, surface/toggle
│   └── .radio__option[]   equal width, radius 6, Inter 12; active takes surface/toggle-active
└── .radio__caption    optional, Lato Regular 11
```

Options divide the group's width equally, so three options each take a third. The active option is the only
one with a fill; the rest are transparent on the group's own surface.

## Tokens

| Token | Applies to |
| --- | --- |
| `--color-surface-toggle` | Group container |
| `--color-surface-toggle-active` | The selected option |
| `--color-text-primary` | Selected option label |
| `--color-text-muted` | Field label, unselected options, caption |
| `--font-label` | Field label and caption |
| `--font-ui` | Option labels |

## Behaviour

- Every option is always visible. There is no menu and no truncation to an ellipsis.
- A long option label wraps onto a second line rather than truncating, which makes the group taller.
  The `k range` options are the worst case in the app.
- Options keep equal widths regardless of label length.

## Accessibility

- The group carries `role="radiogroup"` and an `aria-label` taken from the field label. This is the best
  accessibility story of any control in the system.
- `Source: gap`. The options are buttons without `role="radio"` or `aria-checked`, so membership is announced
  but selection is not. Arrow-key navigation between options is also missing.

## Content

Sentence case. Expand an acronym inside the option where it fits: `All-k (HIPSTER, up to k~1000 h/Mpc)`.
Keep options to a similar length, because they share the width evenly.

## Use it

- Two or three mutually exclusive options that all fit on one row.
- When seeing the alternatives matters as much as picking one.

## Don't use it

- For four or more options, or long labels. Use `SelectField`.
- For an independent on/off setting. Use `Checkbox`.
- For a value on a continuum. Use `Slider`.

## Related

- `Checkbox` — independent settings
- `SelectField` — longer option lists
- **Patterns / Statistic sidebar** — k range, Spectra, Group by
