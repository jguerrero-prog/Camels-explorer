# IconRail

The 48px vertical strip on the far left: avatar and panel switches.

`Source: figma:1113:1583`

## Anatomy

```
.icon-rail              48px wide incl. 1px right border, surface/chrome, padding 12/0/16
├── .icon-rail__avatar    32px circle
└── .icon-rail__button[]  32px, radius 9, 16px icon; active takes border at 60%
```

## Tokens

| Token | Applies to |
| --- | --- |
| `--color-surface-chrome` | Rail fill |
| `--color-border` | Right border, avatar fill, active button fill at 60% |

## Behaviour

- 48px total width including its border, so the sidebar beside it starts at exactly 48.
- Buttons are 32px in a 48px rail, leaving an 8px margin either side.
- One panel is active at a time.

## Accessibility

- Buttons carry `aria-label` and `aria-pressed`, so both purpose and state are announced. Icons are
  `aria-hidden`. This is the correct pattern for an icon-only toggle.
- `Source: gap`. No `role="navigation"` landmark, and no visible focus ring.

## Content

Labels name the panel: "Project", "Files", "Settings".

## Use it

- Once, as the app's outermost left edge.

## Don't use it

- For actions. It switches panels; the toolbar acts on a tile.
