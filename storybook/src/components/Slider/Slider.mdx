## Behaviour

- The visible track is decorative. A native `input[type=range]` sits transparently on top, so keyboard,
  pointer and assistive input all work without reimplementation.
- `step` defaults to 1. Pass a fractional step for a narrow range: a 0.1 to 0.5 range at step 1 can only ever
  sit at its minimum.
- `formatValue` controls the readout only, never the value. Use it for units and precision.

## Accessibility

- The native range input carries the role, the value and keyboard support: arrows step, Home and End jump to
  the bounds.
- `Source: gap`. The input has no `aria-label`, so it is announced without its field name. The visible label
  is a sibling `p`, not a `label` element. Associating them is a one-line fix.
- The thumb has no focus ring of its own, so keyboard focus is invisible against a dark panel.

## Content

Label in sentence case with units in square brackets. The value shows units only when they are not already
in the label. Snapshot shows `33`, not `snapshot 33`.

## Use it

- A bounded numeric range where the approximate position matters more than the exact figure: Snapshot, Grid
  size, Threads, Bins.
- Through `OptionSlider` when the underlying values are a fixed list rather than a number.

## Don't use it

- When the exact value is typed rather than scrubbed. Use `NumberStepper`.
- For two bounds at once. Use `RangeFilterControl`.
- For an unbounded value.

## Related

- `OptionSlider` — the same control indexed over a list of values
- `NumberStepper` — typed entry
- `RangeFilterControl` — two thumbs, min and max
